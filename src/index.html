A LITTLE HELP

你的隨身閱讀空間

開啟文件

拖曳或選取 Markdown 檔案，也能貼上文字。若文件引用本機圖片，請匯入包含文件和圖片的共同上層資料夾。資料夾內的 Markdown 連結也能互相跳轉。

離線與隱私

線上版會自動下載完整離線功能；待頁首顯示「可離線使用」後，即可斷網重新開啟同一網址，包含圖表與公式。請使用同一瀏覽器；清除網站資料後需重新連線下載。下載 ZIP 版完整解壓縮後也可直接離線使用。匯入或貼上的文件、本機圖片與閱讀位置會自動保存在此瀏覽器，不會上傳。等待頁首顯示已保存後，離線重開會自動恢復。清除按鈕會刪除保存的文件、圖片與進度；清除網站資料或更換瀏覽器也會失去這些本機資料。主題與字級偏好也會保留。遠端圖片需要你主動允許才載入。

備份與還原

左側「備份文件庫」可下載 .inkread 檔，包含文件、本機圖片與每份閱讀位置。到另一台電腦或瀏覽器，按「還原文件庫」選取備份，預設合併並保留現有資料；同路徑文件與圖片可逐項比較，再選目前版本、備份版本或「保留兩份」。保留兩份會自動為備份版本重新命名，並分開保存同路徑圖片，各自保留圖片連結與閱讀進度。也可切換整庫取代，請先備份目的地資料。備份與還原可完全離線處理，備份含文件內容且未加密。新裝置仍需先備妥墨閱程式。遠端圖片與載入許可不會帶入。

列印與 PDF

按右上角列印按鈕，再選擇「另存為 PDF」。寬表格建議使用橫向紙張；圖表與公式會一起列印。

鍵盤操作

在閱讀畫面直接貼上文字，也能建立文件。支援近期 Chrome 與 Edge。
