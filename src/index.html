A LITTLE HELP

你的隨身閱讀空間

開啟文件

拖曳或選取 Markdown 檔案，也能貼上文字。若文件引用本機圖片，請匯入包含文件和圖片的共同上層資料夾。資料夾內的 Markdown 連結也能互相跳轉。

離線與隱私

所有功能與字型已隨包附上。文件不會上傳，也不會在關閉或重新整理後保留；主題與字級偏好會儲存在此瀏覽器。遠端圖片需要你主動允許才載入。

列印與 PDF

按右上角列印按鈕，再選擇「另存為 PDF」。寬表格建議使用橫向紙張；圖表與公式會一起列印。

鍵盤操作

O 開啟文件　/ 搜尋文件　Esc 關閉對話框

在閱讀畫面直接貼上文字，也能建立文件。支援近期 Chrome 與 Edge。
